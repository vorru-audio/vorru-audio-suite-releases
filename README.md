# Vorru Audio Suite - Downloads

## Instalar

Abra a pagina Releases.
Baixe o VorruAudio-Suite-Setup-<versao>.exe mais recente.
Execute e siga o assistente.
Abra a DAW, faca um rescan de plugins.

## Requisitos

Windows 10/11, 64 bits.
DAW com suporte a VST3.

## Como usar

Abra o programa Vorru Audio Suite no menu Iniciar para ver o catalogo e
instalar os plugins desejados.

Mais detalhes estao no README do projeto principal.
